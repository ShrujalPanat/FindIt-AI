# 🔎 FindIt AI — Campus Lost & Found

> **My first website as a B.Tech CSE student — built to solve a simple campus problem with a little AI.**

FindIt AI is an AI-powered campus Lost & Found platform designed to make it easier for students to report lost or found belongings, discover relevant items, and safely submit claims.

## 🌱 About the Project

I am a **first-year B.Tech Computer Science Engineering student**, and FindIt AI is my **first complete website/project**.

I built this project as part of my semester work for **Session 2026–27**. The idea started with a simple question:

**“What if finding a lost item on campus could be as easy as searching for it online?”**

Instead of relying only on notice boards, WhatsApp groups, or word of mouth, FindIt AI brings the process into one organized web application.

## ✨ Features

- 🔴 **Report Lost Items** — Report belongings that have been lost.
- 🟢 **Report Found Items** — List items found around campus.
- 🤖 **AI Match Assistant** — Find possible matches between lost and found items.
- 🔍 **Search & Browse** — Search through organized Lost and Found sections.
- 📋 **Claim Item** — Submit a claim for a found item.
- 🔄 **3D Claim Experience** — An interactive card-flip claim flow.
- 👤 **My Claims** — Track submitted claims and their status.
- 🛡️ **Admin Claims** — Admins can review, approve, or reject claims.
- 🌓 **Light / Dark Theme** — Switch between themes.
- 📱 **Responsive UI** — Designed for desktop, tablet, and mobile.
- 🎨 **Campus-inspired Design** — A clean blue/navy interface inspired by a college environment.

## 🧠 How It Works

**Lost Item → Search / AI Match → Possible Found Item → Claim → Admin Review → Resolution**

The goal is to replace scattered posts and messages with one organized place where students can report, search, match, and claim items.

## 🛠️ Tech Stack
